# ESP32 Web Dashboard

An ESP32 hosting its own web server and serving a control page to any browser on the
same WiFi network.

- **`webserver-basic/`** — a minimal ESP32 `WiFi.h`-based HTTP server.
- **`website-ui/`** — the same idea with a fuller served page/UI.

Fill in `YOUR_WIFI_SSID` / `YOUR_WIFI_PASSWORD` in each sketch before flashing.
