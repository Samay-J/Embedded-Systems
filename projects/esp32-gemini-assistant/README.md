# ESP32 Gemini Assistant

An ESP32 that calls the Google Gemini API over HTTPS (via `HTTPClient` +
`ArduinoJson`) — a minimal voice/text-assistant style integration running directly on
the microcontroller.

Fill in `YOUR_WIFI_SSID`, `YOUR_WIFI_PASSWORD`, and `YOUR_GEMINI_API_KEY` (get a key
from [Google AI Studio](https://aistudio.google.com/apikey)) before flashing.
